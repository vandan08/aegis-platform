01Get an identity

The console is a public OAuth2 client, so it has no secret to hide behind. It uses PKCE: a one-time verifier is generated in your browser, only its SHA-256 hash travels with the authorization request, and the authorization code is worthless to anyone who cannot produce the original verifier.

This page keeps the access token in sessionStorage so a refresh does not drop your session mid-demo. A production single-page app should not: it would put the token in a backend-for-frontend session instead, so no script on the page can read it.
